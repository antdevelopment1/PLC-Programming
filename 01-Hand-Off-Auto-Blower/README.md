# Hand/Off/Auto Blower Control

PLC programming exercise implementing a basic Hand/Off/Auto blower control architecture.

## Platform

- RSLogix Micro Starter Lite
- MicroLogix 1100
- Ladder Logic

## Concepts Practiced

- Discrete input mapping
- Internal binary bits
- Output mapping
- Hand/Off/Auto control
- Separation of physical I/O from control logic
- PLC addressing
