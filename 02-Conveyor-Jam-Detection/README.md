# Conveyor Jam Detection

## Task
Program a conveyor that:
- Starts with a momentary Start button
- Stops with Stop
- Requires E-stop and guard permissives
- Detects a blocked photoeye after 5 seconds
- Latches a jam fault
- Prevents reset while the photoeye is blocked
- Requires Start again after reset
