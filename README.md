# PLC Programming

A growing controls engineering portfolio focused on PLC programming, industrial automation, machine control, diagnostics, and control-system design.

This repository documents my hands-on progression through PLC programming patterns, control architectures, and automation exercises. Each project is built to reinforce not only how ladder logic works, but how industrial control systems are structured, tested, diagnosed, and improved.

## Focus Areas

This repository will progressively cover topics including:

- PLC scan cycle and program execution
- Discrete input and output mapping
- Ladder logic fundamentals
- Start/stop and seal-in circuits
- Hand/Off/Auto control
- Timers and counters
- Permissives and interlocks
- Fault detection and reset logic
- Alarm handling
- Motor control
- Pump control
- Conveyor sequencing
- State machines and sequence control
- Analog signals and scaling
- PID control
- VFD integration
- HMI/SCADA integration
- Industrial communications
- Machine diagnostics
- System integration
- Control-system architecture
- Failure modes and recovery strategies
